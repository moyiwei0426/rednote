# Chengdu AI keyword collection (completed 2026-09-24)

This delivery records the completed Chengdu local collection for **1,575** AI-keyword target notes. Public content was retrieved for **1,515** notes; **60** completed targets had no accessible content at collection time.

`notes_unified.csv` contains public post content and canonical URLs. `comments_unified.csv` contains all collected, accessible top-level comments and accessible replies, with reply relationships preserved through `parent_comment_id`. The `quality` directory contains the target-level completion audit and aggregate comment counts.

The repository intentionally excludes browser profiles, cookies, crawler logs, signed URLs, proxy configuration, and raw author/commenter identity fields.
