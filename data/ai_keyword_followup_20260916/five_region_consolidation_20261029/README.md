## 完整性说明

- 北京、上海及武汉已采到正文的目标：逐项的最新评论翻页状态均为 `complete`；武汉未结清的 54 项不在此完整性结论内。
- 广州质量汇总记录 42,105 条分页状态，全部为 `complete`；另有 122 条评论回复的父关系缺失，已在数据中标记。
- 成都交付汇总声明覆盖采集时可访问的一级评论和回复；其公开数据包未提供逐线程分页表，因此本索引保留这一证据边界。
- “无可访问正文”是已结束的采集结果，不等同于采到了正文或评论。

逐地区数字及对应路径见 [`region_status.csv`](region_status.csv) 和 [`manifest.json`](manifest.json)。
